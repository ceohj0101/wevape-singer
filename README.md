## 곡 추가하는 법

`index.html` 을 열어 `const ARTISTS = [` 로 시작하는 목록만 고치면 됩니다.

```js
{ title: "곡 제목",
  src: "파일명.mp3",        // 저장소에 올린 mp3 파일명 (비워두면 '준비중' 표시)
  duration: 0,              // 0 으로 둬도 됨 (재생 시 자동으로 읽음)
  tag: "타이틀",
  lyrics: `가사를 여기에 붙여넣기` }
```

가사 줄 앞에 `[0:12]` 처럼 시간을 적으면 노래에 맞춰 한 줄씩 따라갑니다.
`[Verse 1]` 처럼 대괄호만 있는 줄은 구간 제목으로 표시됩니다.

mp3 와 앨범 이미지는 이 저장소 최상단에 그대로 올리면 됩니다.
